# MergeZoo

Merge animal balls in a glowing rainbow arena and evolve them to the final form - the Dragon.

10 evolution tiers (mouse -> dragon), every animal with its own sound effect, character picker, auto-rain mode, combos, and a dragon finale.

Vanilla JS + Canvas. No build step. Static site.

## Deploy
Any static host. On Vercel: import repo, framework = Other, done.
